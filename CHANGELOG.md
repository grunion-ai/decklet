# Changelog
## 0.3.3 — the scale never crowds
- import-html **fit cap**: a role is its modal signature **capped by the tightest row wearing it**. The walker measures every boxed text row's `_fit` — the largest font-size at which it keeps its source line count inside its box — and `detectRoles` lowers the role to the smallest `_fit` below the modal (leading re-read from a real mockup signature at or below the cap). The scale may shrink a row, never crowd it; the cap is reported in `model.report.json` (`conflicts.<Role>.cap`). On a dense data deck this took Caption/Label 14 → 12 and removed every overflow and chip misalignment.
- verify parity is **hard again** for overflow and extra lines; a snapped row is tolerated only when it renders *fewer* lines than its source (collapsed inline runs), reported as crowding.
- import-html footer: a right-anchored hugging row matches the master by **either edge** (a footer whose text changes grows leftward; the left edge drifted 55px and the row was being hidden on one slide, leaving the generic pinned counter to collide with it). Typed page counts (`· 2/5`, `3 / 6`, `Page 2 of 5`) are stripped from the footer text before the vote — the engine renders the counter.
- import-html: a row whose first font family differs from its role's is a snapped row (`_src`), so the AE mask covers it.
- verify: the AE failure message names the pass column (after masks), not the raw diff.
## Unreleased
- **Motion vocabulary.** `anim` grows from one word to four — `rise` (text), `fade` (quiet chrome), `pop` (stats, tiles, images), `wipe` (bars, lines, rules) — each a role-sized entrance, staggered 120 ms in model order on slide **entry** only. The renderer whitelists the four (an invented anim paints nothing and takes no stagger slot) and `validate` rejects anything else. One `prefers-reduced-motion` guard turns all of them off; print, the contact sheet, the `⤓` PDF and `verify` draw the settled frame, so motion cannot move what is measured or exported.
- **The explainer moves, and shows itself moving.** deck.html is now 12 slides: every headline enters, the chart wipes in, and two new slides — MOTION (the four anims demonstrated live, each tile arriving with its own caption) and THE EDITOR, FILMED (three inlined GIF clips: drag + multi-select, retype + the floating toolbar, contact-sheet reorder).
- **Filmed clips as a build product.** `docs/record-clips.mjs` drives deck.html with Playwright, films model-space crops of the real editor, encodes them with ffmpeg (48-colour palette, 10 fps, ≤ 3 s → 26–99 KB each) and writes the base64 back into `examples/explainer/model.json`. Re-run it, rebuild, and the clips are current — no screen capture in the loop. The deck stays one file with zero network at ~270 KB.
- README demo re-recorded on the 12-slide deck: it pages through slides that animate in, holds on the filmed clips and the MOTION slide, then reorders and writes a PDF (10 fps, 64-colour palette, no dither — 937 KB for 12.6 s).

- Contact sheet: `← Back` button top-left (aria-label "Back to slide (Esc)") closes to the current slide.
- Present mode (fullscreen) allows text editing: select text → the floating toolbar appears above the selection and pins the peek HUD; hidden when nothing is selected. The resize nib still never draws in present mode.
- Toolbar: inline segment is `B I U S̶` only (sub/superscript buttons removed — existing `<sub>`/`<sup>` runs still render, baseline shift only). ## 0.3.2
- verify: AE pixel diff was a silent pass — `magick compare` exits 1 whenever the images differ and prints `AE (normalised)` on stderr; the parser read that as NaN → 0 → PASS on every deck. Now parses the leading number and throws on anything else. Gate test renders a red box against a blank reference and asserts the pixel count.
- verify: AE for imported decks is three columns — raw · chrome masked · chrome + snapped rows masked (the pass column), mirroring the harness proof: deck-wide chrome and rows the type scale changed deviate from the mockup on purpose. Masks come from the deck (`data-m`, supertitle slot, `_src` + `_box`) and the importer's `model.report.json` (`--report`, default beside the deck). `--fonts <css url>` injects a webfont stylesheet at test time only so the shot uses the reference's font build; the counter is hidden for the shot.
- verify: layout parity — a row the scale changed (`_src`, rendered as `data-snapped`) may wrap or crowd differently from its source; that is reported as **scale crowding** for a human decision, never a failure. Unchanged rows, `nowrap` rows and canvas bounds stay hard.
- import-html: hug = content width == inner width. The old `max-content` probe is a no-op on table cells, so a 58px heatmap `td` read as a `w:'auto'` chip and lost its box and centring. Vertically centred single lines (td / flex centre) take `y` from the glyph rect. Runs lose locked type keys (`font-size`/`family`/`lh`/`ls`) and mark the row `_src` — ported from the harness extractor. Gate tests for all three.
## 0.3.1
- PDF export: layered rasterization fixes missing images in WebKit. Safari fired the foreignObject image's onload before the nested `<img>` it contained had decoded (data: PNGs above ~20 KB came out blank). `⤓` now awaits `document.fonts.ready`, rasterises the foreignObject pass with `img`/`svg` rows as hidden placeholders, then draws each `img` from a decoded `Image` and each inline `svg` from its own serialised `Image` at the row's rect, in model z-order (object-fit cover/contain + object-position, border-radius clip, opacity honoured). Chromium output is unchanged on slides without media. `print()` remains the fallback.

## 0.3.0 — initial public release

- Engine: single-file JSON-model deck with in-place editor — drag, ⌘ multi-select, double-click text edit with B/I/U/S + sub/sup marks and colour runs (swatches limited to the deck's own colours), corner-nib resize, persisted undo, floating role toolbar, `+` Text/Box/Slide, contact sheet (select / pointer-drag reorder with FLIP, mouse + touch / duplicate / delete; usable in present mode), fullscreen presentation with hover-peek HUD (pinned while a menu or the sheet is open), per-slide backgrounds.
- PDF: `⤓` writes a true slide-sized PDF in-file (foreignObject → canvas 2× → JPEG → hand-written PDF with byte-exact xref; zero dependencies). Verified in Chromium; Safari's foreignObject raster path is unconfirmed and falls back to `print()`. `⌘P` remains the paper path with named Letter/A4 page sizes (Safari-safe).
- Model: eight-role strict type scale (Title, Supertitle, H1, H2, Body, Caption, Label, Stat — Title is the display size for cover/closing headlines, H1 the content-slide title; rows can never carry font/size/lh/ls), `styles.margin` content-inset token (footer counter sits on it), deck-wide chrome with partial per-slide overrides, layout slots + deck-scope slots, master layer with fork/hide and inline footer counter, primitives box/tile/bar/line/donut/svg/img, `nowrap` / `w:'auto'` / padding tokens for text fit, `anim:'rise'`.
- Formats: `slides` (960×540, 1600×900). Experimental page-size presets `carousel`, `carousel-4x5`, `document-letter`, `document-a4` (no text flow).
- CLI: `bin/validate.mjs` (pure Node), `bin/create.mjs` (per-deck storage namespace from the model hash, style.json tokens/roles merge), `bin/verify.mjs` (layout parity + AE + contract), `bin/import-html.mjs` (HTML pages → model with master/slot/role lifting and line-count intent).
- SKILL.md agent authoring contract, four examples, `node --test` gate with optional live browser proofs.
