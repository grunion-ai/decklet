# decklet brand

The logo mark and its generation pipeline. Selected 2026-08-23 from the
candidate sheet in [docs/decklet-candidates.png](docs/decklet-candidates.png).

## The mark — "dcard"

A lowercase **d** whose bowl is a 16:9 slide: the letter of the name and the
unit of the product in one shape. One colour, no masks, no gradients; stroke
4.5 on a 48-unit grid (favicon: 6, optical correction). Generated by
`MARKS.dcard` in [build-logos.mjs](build-logos.mjs).

## Decisions (2026-08-23)

| # | Decision | Choice |
| --- | --- | --- |
| 1 | Mark | **F · dcard** over stack / fan / nib / roles / peek / file — only candidate that reads at 16 px *and* is ownable |
| 2 | Palette | grunion family: blue `#2563eb`, ink `#0c1b33`, cream `#e0dcd4`, sky `#60a5fa` (same as weave) |
| 3 | App-icon tile | blue squircle (rx 11), cream mark |
| 4 | Lockup | inline, mark scaled to the wordmark's ascender height, "decklet" lowercase 600, −0.02em |
| 5 | Wordmark font | Outfit → Inter → system-ui (no webfont; the lockup SVG uses a stack) |

## Regenerate

```
node brand/build-logos.mjs                 # assets/
node brand/build-logos.mjs docs --candidates   # candidate sheet
node --test brand/build-logos.test.mjs
```

PNG previews: `node brand/render-png.mjs in.svg out.png [scale]` (Playwright
Chromium — ImageMagick drops SVG masks).
