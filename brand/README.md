# decklet brand

The logo mark and its generation pipeline. Selected 2026-08-23 from the
candidate sheet in [docs/decklet-candidates.png](docs/decklet-candidates.png).

## The mark — "stack"

Three 16:9 slides stacked back to front — a deck, small. One colour; the
under-cards are cut with SVG masks (gap 2.5, favicon 3.5) so every asset is
transparent-safe. 48-unit grid. Generated by `MARKS.stack` in
[build-logos.mjs](build-logos.mjs).

## The loader — cycling the deck

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/decklet-loader-dark.gif">
  <img src="assets/decklet-loader-light.gif" width="96" height="96" alt="decklet loader: slides cycling through a stack">
</picture>

Each card advances one slot — the front card drops behind the deck while a new
one fades in at the back. One step leaves the picture identical to the start,
so a single step loops seamlessly (0.9 s). The under-card cuts carry the same
keyframes as the cards cutting them. SMIL only (`assets/decklet-loader.svg`),
so it animates inline, in `<img>`, and as a CSS background; the GIFs exist
because GitHub's image proxy does not run SMIL.

## Regenerate

```
node brand/build-logos.mjs                 # assets/
node brand/build-logos.mjs docs --candidates   # candidate sheet
node --test brand/build-logos.test.mjs
```

PNG previews: `node brand/render-png.mjs in.svg out.png [scale]`; GIFs:
`node brand/render-gif.mjs` (steps the SVG's own SMIL clock, then ffmpeg).
Both use Playwright Chromium — ImageMagick drops SVG masks. Env: `PW_ROOT`
(dir holding `node_modules/playwright`), `CHROME` (executable), `FFMPEG`.
